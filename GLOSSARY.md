# Pullbureau vocabulary

The scene represents an organization's pull request activity as a public service office. Domain names below describe data; the localized UI can use the Portuguese labels.

| English | Portuguese | Meaning |
| --- | --- | --- |
| Bureau | Repartição | The organization's entire office scene |
| Counter | Guichê | A repository with an open PR or recent activity |
| Closed counter | Guichê fechado | A repository inactive for 14 days or outside the visible-counter limit |
| Ticket number | Senha | A PR number within its repository |
| Queue | Fila | Open, non-draft PRs carrying the readiness label and waiting at a counter |
| In line | Na fila | Waiting for review at a counter |
| Waiting room | Sala de espera | Drafts and PRs without the readiness label; excluded from the queue |
| Ready for review | Pronta para revisão | A queued PR carrying the configured ready label; this marker determines eligibility for a counter queue |
| Attendant | Atendente | Someone who actually reviewed a repository's PRs, rather than merely receiving a review request |
| Actor | Personagem | A person's animated representation in the scene |
| Replay | Replay | A timestamped fixture played through the same client data-feed contract |
| Duel | Duelo | A playful scene showing a review interaction |
| Finisher | Finalização | The closing animation of a duel |

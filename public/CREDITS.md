## Rebuilding assets

Download source packs from the links above, keeping their license files. Existing optimized assets are included, so these imports are optional for normal setup.

```sh
pnpm import-models /path/to/character-gltf-directory
pnpm import-props /path/to/asset-directory
# ASSET_DIR may replace the first argument for either command:
ASSET_DIR=/path/to/asset-directory pnpm import-props
```

Character imports recursively discover `.gltf` and `.glb` files. Prop imports expect this directory layout, matching the relative paths in `scripts/import-props.ts`:

```text
asset-directory/
  kenney-furniture-kit/extracted/Models/GLTF format/
  kenney-car-kit/extracted/Models/GLB format/
  kenney-nature-kit/extracted/Models/GLTF format/
  kenney-city-kit-commercial/extracted/Models/GLB format/
  kenney-city-kit-suburban/extracted/Models/GLB format/
  kenney-city-kit-roads/extracted/Models/GLB format/
  polyhaven-hdri/
```

The selected prop filenames use `.glb`, including the folders named `GLTF format`. Place both named HDRIs from the table in `polyhaven-hdri/`. Import scripts run glTF Transform and overwrite the generated manifests and matching model outputs. Review these changes together. Character imports optimize models and record source bounds; prop imports additionally rescale and recenter geometry and verify output bounds.
